# Seed photos

Put one image per name below in this folder (`.jpg`, `.jpeg`, `.png` or `.webp`, e.g. `rainbow-pothole.jpg`),
then — after running `supabase/seed.sql` — upload them:

```bash
node scripts/upload-seed-photos.mjs
```

Landscape shots around 1600px wide work best (cards crop to 16:10).
